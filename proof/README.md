# Historical v0.1 proof artifacts

This folder is retained from the original uploaded build. Its 126-test results and v0.1 metadata are historical baseline evidence, not the current release totals. Current evidence is in `validation/`, `RELEASE.json`, and `docs/VALIDATION_REPORT.md`.

## Original baseline contents

`pytest-output.txt` and `pytest.xml` contain the original baseline passing suite. `coverage.json` records statement coverage. `synthetic-demo.json` is fictional and contains no real-person findings. `tested-environment.json` is the observed environment, not a lockfile. `wheel-build.txt`, `wheel-install.txt` and `wheel-smoke.json` show local packaging proof without dependency resolution. `source-network-smoke.json`, `environment-limitations.json` and `browser-validation.json` preserve failed/unexecuted validation boundaries. See `docs/VALIDATION_REPORT.md` for interpretation. No credentials or real research media are included.
