# ADR 005: Local reference before production infrastructure

Status: accepted for the local reference.

## Decision

Use a small standalone SQLite/FastAPI implementation to prove record semantics; evolve to multi-worker storage only under measured gates.

## Alternative and reason

Deploying many infrastructure services before proving deduplication and evidence lineage increases complexity without validating the product.

## Consequences

Current performance and security limits are explicit; the reference is not exposed as production SaaS.

Revisit only through a documented change with regression evidence; do not silently expand the reference implementation’s claims.
