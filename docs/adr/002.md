# ADR 002: Versioned relational truth, derived retrieval

Status: accepted for the local reference.

## Decision

Canonical exact words, source revisions, identity evidence, claims and reviews live in the ledger; optional search indexes are derived.

## Alternative and reason

Using embeddings or graph retrieval results as the canonical evidence record would lose reproducibility and permit stale context to appear authoritative.

## Consequences

Writes carry dependencies and invalidate descendants; retrieval/indexing can be rebuilt and must obey rights.

Revisit only through a documented change with regression evidence; do not silently expand the reference implementation’s claims.
