# ADR 004: Human review gates and abstention

Status: accepted for the local reference.

## Decision

Diarization, semantic matching and candidate extraction cannot finalize identity, scope compatibility or claim findings.

## Alternative and reason

An end-to-end black-box verdict pipeline hides identity and scope errors and cannot explain unsupported results.

## Consequences

The reference is useful before full automation; reviewer effort is an explicit cost and evaluation dimension.

Revisit only through a documented change with regression evidence; do not silently expand the reference implementation’s claims.
