# ADR 001: Independent bounded-context application

Status: accepted for the local reference.

## Decision

The ledger owns its IDs, schemas, rights grants, code, database and release gates. Generic provider interfaces are optional.

## Alternative and reason

A cross-product shared canonical graph or imported project specification would couple the work to unrelated assumptions.

## Consequences

Some generic logic may be reimplemented locally, but the system can run and be tested without another private repository.

Revisit only through a documented change with regression evidence; do not silently expand the reference implementation’s claims.
